# 02：把原始单体结果放到各片段位置

运行前：读取单体和聚集体的对应原子，生成 `matrix_f_99.txt` 等刚性位置变换，并写各片段 XYZ 及拼合后的 `aggregate.xyz`。
运行：生成各位置的 C1 参考 RunFile/OneInt。
运行后：调用安装内唯一维护的 RotateOrb，根据同一旋转矩阵将共享原始轨道变为 `f_99_S1.orb`、`f_03_S1.orb` 等位置专用轨道。

原始单体内部坐标保留，聚集体输入只用于确定位置，不对原始轨道作几何形变。
所有原子必须按用户声明对应；程序不自动交换相同元素的 AO 中心。

```bash
bash run.sh ethene_dimer.yaml all
```

每个算例写入自己的 `<project>/`，不同位置不会覆盖共享的旋转前结果。
